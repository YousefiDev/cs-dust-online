SOUNDS
======
The .wav files here are rendered by  tools/gen_sounds.py  (python3 tools/gen_sounds.py) and listed in manifest.json.
Any name in manifest.json replaces the live WebAudio synth. To use your own recordings, put the files here and edit
manifest.json (a name can be one file or a list; a random variant plays each time). Delete a name to fall back to the synth.

Names: weapon keys (ak47 galil sg553 m4a4 m4a1s famas aug awp mac10 mp9 p90 deagle glock usp knife),
reload / reload_<weapon>, dry, hit_head, hit_body, hurt, nade_throw, he, flash, smoke, ring, draw, ui, money,
c4_plant c4_planted c4_beep c4_beep_fast c4_defuse c4_defused c4_explode.
Footsteps: ../footstep_1.wav ... footstep_6.wav

# نسخه بدون Token و تنظیمات ذخیره‌سازی

این نسخه برای اجرای ویرایشگر پیشرفته بدون GitHub Token، Secret، Environment Variable و R2 آماده شده است.

## روش استفاده
1. پروژه را در مخزن GitHub خود قرار بده و از طریق Cloudflare Pages منتشر کن.
2. صفحه `/advanced-map-editor` را باز کن.
3. فایل‌های اصلی JSON و BIN را انتخاب کن و نقاط را روی مپ مشخص کن.
4. روی «دریافت فایل‌های مپ» بزن. مرورگر فایل‌های اصلی و فایل `*-markers.json` را دانلود می‌کند.

## محدودیت مهم
بدون احراز هویت یا سرویس ذخیره‌سازی، سایت نمی‌تواند خودش فایل‌ها را به مخزن GitHub بنویسد یا در فهرست بازی ثبت کند. این نسخه خروجی را روی دستگاه کاربر دانلود می‌کند؛ برای انتشار باید فایل‌ها را دستی در GitHub قرار بدهی. فایل BIN بزرگ هم از این طریق به‌طور خودکار به بازی اضافه نمی‌شود.
